UGO-Omics

Application-oriented candidate discovery platform for underground-organ biology

Start with your biological question. UGO-Omics helps users check whether a gene belongs to an underground-organ candidate module, find candidate modules for a target organ or species, and prioritize validation-ready candidates for functional follow-up.

11-species high-confidence transfer backbone 51-species resource layer 8/8 candidates remapped 7/8 traceable in both new species Application-first interface

Sequence-to-UGO

Map your protein sequence to UGO-Omics orthogroups, candidate modules, UGO scores, biological discovery cases, and validation-priority annotations.

Use this workflow when you start from a protein sequence rather than a known UGO gene ID. The current version provides a local DIAMOND-based workflow using the UGO 11-species protein search database.
1

Prepare protein FASTA

Open an example protein FASTA file. Replace it with your own protein sequence before running Sequence-to-UGO.

Open example FASTA →
2

Run DIAMOND search

Open the one-command shell script for searching your proteins against the UGO 11-species protein database.

Open run script →
3

Map hits to UGO

Open the mapper script that converts DIAMOND hits into UGO orthogroups, candidate modules, scores, and validation priorities.

Open mapper script →

One-command local workflow

bash scripts/run_sequence_to_UGO.sh examples/example_query_proteins.fa example_results/example_query

The interpreted output is example_results/example_query.sequence_to_UGO.tsv.

Gene-list-to-UGO

Map DEG, QTL, GWAS, or candidate gene lists to UGO-Omics orthogroups, candidate modules, scores, and validation-priority annotations.

Use this workflow when you start from a list of gene or protein IDs rather than a sequence. Compact mode maps directly to prioritized UGO candidate modules. Full mode can also use the complete sequence-to-orthogroup lookup from the release archive.
1

Prepare gene list

Open an example gene list. Replace it with DEG, QTL, GWAS, or manually selected genes from your own study.

Open example gene list →
2

Run Gene-list-to-UGO

Open the one-command shell script that maps your gene list to UGO candidate modules.

Open run script →
3

Inspect module summary

View the ranked UGO module summary generated from the example gene list.

Open example output →

One-command local workflow

bash scripts/run_gene_list_to_UGO.sh examples/example_gene_list.txt example_results/example_gene_list_to_UGO

The most useful output is example_results/example_gene_list_to_UGO.module_summary.tsv.
