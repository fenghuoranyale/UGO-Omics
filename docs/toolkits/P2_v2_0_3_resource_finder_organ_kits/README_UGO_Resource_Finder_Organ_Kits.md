# UGO-Omics v2.0.3 Resource Finder + Organ Kits

## Purpose

This toolkit provides one-stop entry points for users who start from a species or an underground-organ context.

## Main components

1. Resource Finder

Users select a species and retrieve:

- candidate modules available for that species;
- top candidate functions;
- available UGO resource layers;
- recommended analysis workflow;
- relevant download files.

2. Organ Kits

Users select an underground organ type and retrieve:

- biological overview;
- prioritized candidate modules;
- recommended workflow;
- suggested validation focus;
- relevant download files.

## Main files

- database/UGO_v2_0_3_species_resource_finder_v1.tsv
- database/UGO_v2_0_3_organ_kits_v1.tsv
- database/UGO_v2_0_3_organ_module_recommendations_v1.tsv
- database/UGO_v2_0_3_resource_finder_organ_kits_metadata_v1.json

## Claim calibration

Resource Finder and Organ Kits provide candidate-prioritization and hypothesis-generation outputs. They should not be interpreted as functional validation.
