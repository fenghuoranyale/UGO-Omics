UGO-Omics

An expression-backed orthogroup resource for comparative underground-organ biology

UGO-Omics integrates underground-organ transcriptomes, orthogroups, candidate prioritization, expanded candidate traceability, benchmark-module recovery, and a static browser for rhizome, tuber/stolon, storage-root, bulb, corm, root-crown, and regrowth systems.

UGO-Omics overview

UGO-Omics combines a six-species expression-backed analytical core, a 51-species broad underground-organ resource layer, a 9-species expanded orthogroup backbone, candidate expansion traceability, known-module benchmark recovery, and a browsable static website.
