UGO-Omics

Underground-organ comparative omics and candidate-transfer platform

UGO-Omics is an expression-backed orthogroup resource for discovering, ranking, and transferring candidate modules across rhizome, tuber/stolon, storage-root, bulb, corm, root-crown, and regrowth systems. It combines species resources, candidate prioritization, expanded orthogroup traceability, known-module benchmark recovery, and interactive exploration tools.

Tutorial / Example Use Case

How to use UGO-Omics to find transferable candidate modules.

Example: finding transferable rhizome candidate modules

  1. Open Candidate Transfer and select a rhizome-related organ category.
  2. Review candidates ranked by recommendation score and UGO score.
  3. Open UGO Score Explorer to inspect traceability, expansion support, benchmark recovery, and annotation interpretability.
  4. Use Orthogroup Detail View to inspect the mapped 9-species orthogroup and benchmark links.
  5. Use Species Browser to identify relevant target species and resource status.

This workflow is designed to generate testable hypotheses for comparative underground-organ biology. It does not replace species-specific functional validation.
