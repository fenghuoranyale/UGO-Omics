# UGO-Omics

UGO-Omics is an application-oriented candidate discovery platform for underground-organ biology.

## Current application layers

UGO-Omics provides four practical entry points:

1. Sequence-to-UGO  
   Map protein sequences to UGO orthogroups, candidate modules, UGO scores, and validation-priority annotations.

2. Gene-list-to-UGO  
   Map DEG, QTL, GWAS, or manually curated candidate gene lists to UGO candidate modules and ranked module summaries.

3. Resource Finder  
   Select a species and retrieve available candidate modules, resource layers, and recommended workflows.

4. Organ Kits  
   Select an underground organ type and retrieve candidate modules, recommended workflows, and validation-focused hypotheses.

## Claim calibration

UGO-Omics outputs are designed for candidate prioritization and hypothesis generation. Candidate traceability, UGO scores, and validation-priority annotations do not constitute functional validation.

## Large files

The public GitHub repository stores the website, JSON layers, lightweight toolkits, compact lookup tables, and example files. Large search databases are distributed through the full release archive and are intended for archival deposition.
