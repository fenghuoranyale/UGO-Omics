# UGO-Omics

UGO-Omics is an application-oriented cross-species platform for underground-organ candidate discovery, candidate transfer, and biological discovery-case exploration.

## Website

- Web platform: https://fenghuoranyale.github.io/UGO-Omics/
- Public repository: https://github.com/fenghuoranyale/UGO-Omics

## What UGO-Omics does

UGO-Omics supports five user-facing discovery workflows:

1. **Check a Gene**  
   Query a gene ID, orthogroup, gene family, or annotation keyword to evaluate whether it belongs to a UGO candidate module.

2. **Find Candidates by Organ**  
   Select an underground-organ type such as rhizome, tuber, storage root, bulb, corm, root crown, or stolon to retrieve prioritized candidate modules.

3. **Find Candidates by Species**  
   Select a species to view candidate modules with homologous members in that species.

4. **Prioritize Validation Targets**  
   Generate a ranked shortlist of candidate modules for functional follow-up, including suggested validation systems and assays.

5. **Biological Discovery Case**  
   Explore conserved candidate modules linking underground-organ growth, renewal, stress resilience, hormone-related transitions, and developmental regulation.

## Resource layers

UGO-Omics currently integrates:

- a six-species expression-backed analytical core;
- an 11-species high-confidence transfer backbone;
- a 51-species broad underground-organ resource layer;
- an application-oriented website;
- a biological discovery-case layer with Figure 8 and validation-ready shortlist.

The 11-species backbone contains 30,121 orthogroups, including 7,378 represented in all 11 species. All eight prioritized candidate modules were remapped to this backbone, and seven were traceable in both newly added species, Panicum virgatum and Dioscorea rotundata.

## Biological discovery case

The v1.9 Biological Discovery page highlights five conserved candidate module themes:

- meristem/regrowth;
- stress resilience;
- hormone-related regulation;
- developmental transcription-factor regulation;
- cell-wall remodeling.

These modules are presented as candidate-prioritization and hypothesis-generation outputs for downstream functional follow-up.

## Claim calibration

UGO-Omics is a candidate-prioritization and hypothesis-generation platform. Candidate traceability, UGO scores, biological discovery cases, and validation-priority rankings should not be interpreted as functional validation.
