# UGO-Omics

UGO-Omics is an expression-backed orthogroup resource and candidate-transfer platform for comparative underground-organ biology.

Website: https://fenghuoranyale.github.io/UGO-Omics/

Repository: https://github.com/fenghuoranyale/UGO-Omics

## Platform functions

UGO-Omics includes:

- Dashboard
- Global Search
- UGO Score Explorer
- Candidate Transfer Tool
- Orthogroup Detail View
- Species Browser
- Candidate Expansion
- Benchmark Recovery
- Candidate Browser
- Top Orthogroups
- Tutorial / Example Use Case
- Downloads

## Main evidence layers

- Six-species expression-backed underground-organ analytical core.
- 51-species broad underground-organ resource layer.
- 9-species expanded OrthoFinder backbone.
- 8/8 prioritized candidate orthogroups remapped to the expanded backbone.
- 8/8 prioritized candidates traceable in newly added broad-layer species.
- 11/15 curated benchmark modules recovered by prioritized candidates.

## Claim calibration

UGO-Omics provides candidate prioritization, cross-species traceability, benchmark-module recovery, and hypothesis generation. It should not be interpreted as functional validation of individual genes.
