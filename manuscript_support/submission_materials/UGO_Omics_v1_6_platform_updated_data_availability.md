# Data availability statement

The UGO-Omics web platform is available at https://fenghuoranyale.github.io/UGO-Omics/. The source files, static website, JSON browser layers, figure source tables, orthogroup summaries, candidate expansion outputs, benchmark recovery tables, supplementary tables, and manuscript-supporting materials are available at https://github.com/fenghuoranyale/UGO-Omics. A Zenodo DOI will be added before final publication. Public RNA-seq datasets and reference genome/annotation resources used in the analysis are listed in Supplementary Tables S1 and S2. The 9-species expanded OrthoFinder summary and per-species representation are provided in Supplementary Table S6. Candidate expansion traceability and Figure 4 source data are provided in Supplementary Table S7. Known-module benchmark seed and recovery tables are provided in Supplementary Tables S8a and S8b. The website page, JSON-layer, and figure/source asset manifest is provided in Supplementary Table S9.
